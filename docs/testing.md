# 仓库整理测试记录

测试日期为 2026-11-26。运行环境为 Windows、Python 3.15.2、Pillow 13.0.0 和本机 Node.js。

## 可安装包

通过 pyproject.toml 构建并安装 `tjc-hmi-toolkit 0.1.0` 成功。测试通过安装后的包执行，避免仅依赖源码目录中的导入路径。

## 默认测试

运行 `python -W error -m unittest discover -s tests -v`，24 项测试全部通过。测试覆盖以下内容。

- 资源目录数量、截断、越界及重叠。
- 固定槽位容量、替换时保留其他字节。
- 控件块序列化、页面索引边界、CRC 损坏检测。
- 清空继承事件、严格字符串编码。
- CRC 表实现与独立逐位参考算法比对。
- 图片游程边界、特殊 literal 标记、截断和索引损坏。
- 图片资源头及配套 PNG。
- 导出文件名校验和 CLI 退出码、JSON 输出。
- 从合成模板经 build_file 生成完整四页工程。
- 重复生成字节一致，以及输入模板保持原有内容。

默认测试运行时生成二进制样本，仓库中保留文字测试代码和示例素材。

`node tests/preview_test.cjs` 通过，覆盖导航、设备状态模拟、模式、补光开关、亮度限幅和紫外锁定反馈。

## 本机真实样本

使用本机 TJC4827T143 原厂模板，已有 outputs 四页工程作为控件模板，配合仓库内 layout.json 和四张背景图，完成以下命令入口检查。

| 入口 | 结果 |
|---|---|
| build | 生成 11,284,510 字节 HMI，内部验证通过 |
| inspect | 导出 JSON，资源及页面信息可读 |
| export | 导出 74 个有效资源 |
| validate --greenhouse --pictures | 10 个保留页槽位、4 个业务页、4 张引用背景通过 |
