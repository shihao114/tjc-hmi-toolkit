## 页面协议

逻辑页号 0—3 分别为总览、环境、设备、灯光，每页加载完成执行 `sendme`。设备命令为六字节帧。

| 首字节 | 操作 |
|---|---|
| 01 | 水泵 |
| 02 | 风扇 |
| 03 | 模式 |
| 04 | 补光开关 |
| 05 | 紫外请求 |
| 06 | 亮度减 |
| 07 | 亮度加 |

每帧后续字节为 `00 00 FF FF FF`。设备状态以单片机回传为准。紫外请求由单片机的功能启用状态和控制策略处理。

## 使用官方工具的验证流程

1. 通过 build 命令生成工程。
2. 在适配目标型号的 USART HMI 工具中打开，核对型号、字库和页面顺序。
3. 编译并记录错误、警告及文件大小。
4. 使用官方工具导出适配屏幕的 TFT。
5. 在屏幕上验证显示、触摸、页号回传和单片机状态刷新。

CRC 和结构校验成功后，仍需按此流程确认实际运行。历史 TFT 的有效校验无法证明它对应本次生成的 HMI。
