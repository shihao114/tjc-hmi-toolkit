# 已观察的工程结构

本说明记录当前样本的结构。模型和软件版本变化时需要重新验证。

## 资源目录

文件开头为小端 uint32 条目数，之后为每项 28 字节的目录。

| 字段 | 字节数 |
|---|---|
| ASCII 名称 | 16 |
| 文件内绝对偏移 | 4 |
| 资源长度 | 4 |
| 标志及其他元数据 | 4 |

代码保留全部模板字节，通过有效目录定位资源。当前样本在 `0x80000` 和 `0x380000` 存在镜像目录。不同样本的空目录使用全 FF 等标记。

`main.HMI` 的已知样本清单从第 96 字节开始，每项 16 字节，由 8 字节类别和 8 字节资源名组成。清单顺序决定逻辑页面 ID 和图片 ID。

资源的名称编号、物理存储顺序与逻辑 ID 需要分别处理。

## 页面与控件

页面头长度为 56 字节。第 4 字节位置为页面资源长度，第 8 字节位置为控件索引地址，第 12 字节位置为控件数。当前解析器支持索引紧随 56 字节页面头的布局。

每个控件索引占 12 字节，保存相对偏移、长度及其他字段。相对偏移以页面头结尾为基准。控件内部包含带长度的属性名、属性块、事件字符串，最后以零长度终止。

页内修改需要重新建立控件索引和数量。生成器在剩余页面槽位补零，并更新页面总长度和 CRC。

页面 CRC 采用多项式 `0x04C11DB7`，初始值 `0xFFFFFFFF`，每输入字节推进 32 位，再按已观察规则追加长度、数量及两个头部字节。实现和独立逐位参考算法在测试中比对。

## 图片

当前支持以 `0A 60 01 03` 开头的运行图片及配套 PNG 源资源。RGB565 数据按行组织，每组包含计数半字节和八个颜色值，并使用行索引及计数索引。

编码器将同色连续段限制在 14 个像素以内，避免触发首半字节 `0xF` 的特殊情况。解码器支持样本中该位置表示首像素计数 1 的形式，此行为经过配套 PNG 全像素比对。

生成器在 256、128、64、32 色之间尝试量化，再选择足够大的成对图片槽位。

## 工程写入策略

本版采用固定槽位替换策略，保留资源偏移、容量和镜像目录。该实现适用于当前生成路线。

历史最终样本存在图片条目缩短并重排的情况，因此“任意 HMI 资源长度都必须不变”缺少依据。资源重排需要同步目录、镜像及其他关联数据，相关自动重建功能有待后续验证。
