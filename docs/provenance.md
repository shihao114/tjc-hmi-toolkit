# 来源与发布记录

本仓库从当前项目的本地开发材料整理，新增了可安装包、命令行、固定槽位生成器和合成工程测试。

| 内容 | 本地来源及整理方式 |
|---|---|
| page.py | 从已有 page_format.py 整理，增加边界、终止符和严格编码检查 |
| checksum.py | 依据已有 tft_hmisafe.py 的 type-10 算法及页面校验实践，提取所需部分 |
| 图片编码 | 依据 edition.py 的编码流程整理，增加边界检查和已验证 literal 块支持 |
| 工程生成 | 从 edition.py 的布局写入流程整理，参数化并移除顶层执行 |
| 背景图、预览 | 来自本次温室界面的绘图与预览产物 |
| 预览测试 | 从已有 verify.cjs 整理为仓库相对路径 |
| CLI、合成工程测试 | 本次仓库整理新增 |

已有本地解析代码包含较早工具链中的内容，其完整上游来源和许可证尚待核对。仓库所有者应据此决定发布范围和项目许可证，当前仓库保留这一来源记录。

原厂 HMI、TFT、字库和官方可执行程序由使用者在本地提供。仓库中的默认测试通过合成数据运行。

本仓库按技术观察记录私有文件格式的部分行为。官方产品名称用于描述兼容目标。
