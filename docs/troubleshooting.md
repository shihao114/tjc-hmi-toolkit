# 常见问题

## 找不到透明触摸控件模板

controls-template 需要包含 m 类型透明触摸热区，此外还需要 y 类型页面和 t 类型文字。使用官方工具建立一个包含这些控件的兼容工程，并指定该文件。既有兼容四页工程也可提供所需结构。

## 页面或图片槽位不足

生成器会报告需要的字节数和当前容量。可以减少控件数量、简化底图，或者准备包含更大资源槽位的适配模板。图片会尝试多档调色板量化。

## 官方编译提示无效变量或控件

检查控件模板与目标型号的兼容性，核对事件中页面名、控件名及字体 ID。生成器会清空继承的事件内容后再写入示例事件。保留编译日志可用于扩展后续兼容性检查。

## 字体或读数显示不完整

核对 layout.json 中的 font ID 与模板字库，确保包含数字、小数点、负号、百分号、ppm 和 klx 等动态文本字符。当前 txt_maxl 设为 24。

## 单片机无法识别页面

确认四个业务页位于逻辑 ID 0—3，且加载完成事件包含 sendme。串口波特率为 115200。使用 validate 的 greenhouse 选项检查这套布局，硬件上还需要验证串口帧和 MCU 页号处理。
